# Niri keybinds

`Mod` is the Super (Windows) key. `XF86` keys are the laptop media
keys and work on the lock screen too.

## Apps

- `Mod-t` terminal (kitty)
- `Mod-n` code editor (kitty session that picks a project and opens nvim)
- `Mod-b` Zen browser, `Mod-shift-b` private window
- `Mod-e` file browser (yazi in kitty)
- `Mod-shift-e` GUI file browser (thunar)
- `Mod-c` chat and email (kitty session with nchat and aerc tabs)
- `Mod-space` app launcher (vicinae)
- `Mod-m` logout and power menu (noctalia panel)

## Focus and workspaces

- `Mod-1` through `Mod-0` jump to workspaces 1 through 10
- `Mod-up` and `Mod-down` previous and next workspace
- `Mod-left` and `Mod-right` focus left and right column
- `Alt-tab` focus next window

## Moving windows

- `Mod-shift-up` and `Mod-shift-down` move window up, into the
  workspace above if needed
- `Mod-shift-left` and `Mod-shift-right` move column left and right
- `Mod-p` move window to next monitor
- `Mod-bracketleft` and `Mod-bracketright` consume window into a
  column, or expel it back out

## Layout

- `Mod-minus` and `Mod-equal` shrink and grow column width
- `Mod-shift-minus` and `Mod-shift-equal` shrink and grow window height
- `Mod-f` maximize column, `Mod-shift-f` maximize window to edges
- `Mod-ctrl-f` fullscreen
- `Mod-v` toggle floating
- `Mod-shift-t` toggle tabbed column display
- `Mod-escape` close window

## Capture and share

- `Mod-F6` screenshot to clipboard
- `Mod-shift-s` save screenshot to file and copy it
- `Alt-p` screenshot a picked window and sync it to the tablet,
  `Alt-shift-p` inverted
- `Alt-v` clipboard history
- `Alt-shift-c` toggle dynamic screencast of the picked window

## Sound, light, graphics

- Volume up, down, and mute; microphone mute
- Brightness up and down
- `XF86Launch3` toggle integrated and hybrid graphics
- `Mod-shift-n` toggle night light (works locked)
