# Sioyek keybinds

Sioyek keeps its default bindings except for the overrides below. The custom
bindings are configured in `modules/graphical/sioyek.nix`; run `rebuild` after
changing them.

| Action | Keys |
| --- | --- |
| Close window | `q` |
| Open command prompt | `Ctrl-p` |
| Toggle custom color mode | `Ctrl-d` |

Sioyek also starts with custom color mode enabled, horizontal scroll lock
toggled on, and the page fitted to the window width. These startup settings are
configured separately from the keybindings.
