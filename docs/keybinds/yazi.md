# Yazi keybinds

Only the custom additions are listed here; everything else is stock
yazi. All of these are prepended to the manager keymap.

## Devices and mounts

- `g` then `m` jump to a mounted device (automounts if needed)
- `M` mount menu
- `P` mount a device over MTP, SMB, or SFTP
- `M` then `u` unmount and eject

## Files

- `enter` enter directory, or open file smartly
- `F` smart filter
- `shift-s` symlink yanked files by absolute path
- `C` compress selection into a zip (ouch)
- `tab` drag and drop selection out (ripdrag)
- `?` size of selection or current directory

## Shell

- `` ` `` jump with bunny
- `'` then `;` open interactive fish shell here
- `'` then `:` same, blocking until it exits
