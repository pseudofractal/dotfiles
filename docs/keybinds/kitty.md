# Kitty keybinds

These custom bindings are configured in `modules/graphical/kitty.nix`. Kitty's
other default bindings remain available.

| Action | Keys |
| --- | --- |
| Set tab title | `Ctrl-r` |
| Set tab title to “Code Editor” | `F1` |
| Set tab title to “CLI” | `F2` |
| Set tab title to “Runners” | `F3` |
| Clear tab title | `Ctrl-Shift-r` |
