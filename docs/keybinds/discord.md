# Discord keybinds

The desktop Discord client's push-to-talk shortcut is configured in
`modules/graphical/discord.nix`.

| Action | Keys |
| --- | --- |
| Push to talk | `F8` |

Push to talk is disabled by default in the seeded config; enable it in Discord's
voice settings to use this shortcut. Concord is the separate terminal Discord
client and has its own [keybinds](concord.md).
