# OpenCode Config

This directory contains the OpenCode configuration split into Nix modules.

## Layout

- `default.nix` base OpenCode settings and imports
- `mcps.nix` MCP server configuration
- `tools/` custom tool definitions
- `skills/` agent skill definitions
- `rules/` global instruction rules

## Notes

- Tools, skills, and rules are installed into `~/.config/opencode/` via Nix.
- Rules are referenced from `~/.config/opencode/config.json` generated by Nix.
